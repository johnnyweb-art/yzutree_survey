手機網頁量測原型，版本 0.4。HTML / CSS / JavaScript，無外部 CDN、無安裝依賴，可部署至 GitHub Pages。所有盤查資料在目前瀏覽器本機儲存，不會送到伺服器。

## 已實作

- 校園 13 區與原計算表的 99 種樹種選單。
- 後置相機準星、手機角度讀取、水平校正、穩定度檢查。
- 樹高及東西／南北冠幅的平地幾何估測；感測器不可用時可填工具角度測試。
- 樹旁 GPS 定位與定位精度記錄。
- 最粗三幹周長手填、單株碳存量與 CO₂ 當量、兩個模型差異。
- 本機儲存、重複編號檢核、修正紀錄及保留修正前快照。
- 真正的 `.xlsx` 匯出（含原公式），及 JSON 備份／合併還原。

此版本不包含全班雲端同步、照片上傳、iNaturalist 自動串接、AR 空間追蹤或離線快取。不要把瀏覽器本機保存視為全班資料庫。

## 現場量測程序

1. 先以捲尺量出鏡頭離地高度，輸入 App（不預填，請輸入實際量得值）。
2. 直向握持、使用後置相機。鏡頭瞄準與鏡頭同高的標記，按水平校正。不是平放手機後歸零。
3. 樹高：在與樹基等高的平坦地面，同站位、同鏡頭高度，先記錄樹基俯角，再記錄樹頂仰角。
4. 冠幅：找出兩端樹冠的**垂直地面投影**，站在兩點連線延長線、樹冠外側，依序記錄近端、遠端地面俯角，全程固定鏡頭高度與站位。東西向及南北向各做一次；建議同伴指認端點。樹影不是垂直投影。
5. 到樹旁取得定位，填周長及基本資料，保存紀錄並匯出。

### 量測假設與限制

- 距離 `D = h / tan(-β)`，樹高 `H = D × (tan α − tan β)`；h 為鏡頭離地高度，β 為樹基俯角（負值），α 為樹頂仰角。冠幅 = h/tan(-遠端角度) − h/tan(-近端角度)，要求近、遠兩點與站位共線且地面等高。
- 必須地面等高；樹高模式假設最高點大致在樹基正上方。斜坡、傾斜樹、寬冠側枝與錯誤頂點都可能造成明顯誤差。
- 俯角限 5°–75°，樹頂仰角限 0°–60°。接近水平的俯角對角度誤差非常敏感。
- 羅盤只是參考：有絕對方位才顯示，否則要求使用者依地圖／可靠羅盤確認。尚未補償磁偏角，不保證精確真北。
- 手機感測器捕捉要求讀值新鮮、左右扶正、直向握持、相機啟用及穩定至少約半秒以上。
- 所有此法尺寸均標記為估測。尚未驗證實體 iPhone / Android 的相機、姿態軸及校園精度。

## 手機現場驗證清單

先各用一支 iPhone 與 Android 測試，勿直接用於正式成果：

1. HTTPS 上的相機、感測器、定位允許／拒絕流程。
2. 鏡頭水平時約 0°，往上為正、往下為負；換方向仍一致。
3. 選已知高度的標記，以及捲尺量好的 3 m、5 m、8 m 地面端點，每點各測三次。
4. 選 5–10 株不同樹形，用捲尺基線＋工具讀角作為樹高對照，兩方向複測。
5. 比較兩向冠幅與捲尺，記錄絕對誤差、相對誤差、機型與地面條件。
6. 實際保存一筆、重新開啟、下載 Excel、在 Excel 中改周長，確認公式重算。

## 0.3 樹高逐步量測（2026-10-05）

樹高改成五步驟：填距離／鏡頭高度 → 啟用與水平校正 → 樹基 → 樹頂 → 結果。預設捲尺實量水平距離；每一步只顯示目前需要的控制項，校正及記錄成功後自動前往下一步。可回上一步或重新量測，後續暫存數據會同步失效；重新開啟樹高時清空距離與鏡頭高度，避免沿用上一站數值。手動工具角度收在進階選項，不用於取代真實手機現場驗證。既有冠幅與 Excel 碳公式保留。已加入流程防跳步、回退、重開和冠幅相容測試，共 16 項通過。

## 0.4 冠幅逐步量測

東西、南北向皆採準備 → 校正 → 近端第一點 → 遠端第二點 → 結果。兩點皆為樹冠垂直地面投影，非枝梢或樹影。第二點距離必須大於第一點；支援回退重測，兩次角度及距離會保存到 JSON 與 Excel 原始紀錄。碳存量與 Excel 計算公式未變。舊影片冠幅片段已加版本提醒。感測器精度仍需手機現場與捲尺比對；無法確認共線或等高時不適用此估測。
