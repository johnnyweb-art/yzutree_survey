01

手機準備

以 HTTPS 網址在 Safari 或 Chrome 開啟，允許相機、動作感測與定位。直向握持，使用後置相機。

先用捲尺量出「鏡頭到地面」高度；每次瞄準保持鏡頭在相同高度。把鏡頭對準與鏡頭同高的標記，按「水平校正」，不要把手機平放後歸零。

02

樹高

找平坦地面，確定樹基與站位等高、樹頂大致位於樹基正上方。依序瞄準樹基中心與最高枝梢，保持站位及手機高度不變。

預設用捲尺實量水平距離，減少距離推估的誤差；也可選鏡頭高度與樹基俯角推算距離。水平距離從鏡頭正下方量到樹基，不可用 GPS 兩點距離或斜距代替。換約 90° 的方向複測，差異超過 10% 或 1 m 時應重量。

03

冠幅

東西向：先找樹冠最西與最東端在地面的投影。站在兩點連線的延長線、樹冠外側，兩個地面投影點都在前方。填鏡頭離地高度 → 水平校正 → 記錄近端第一點 → 記錄遠端第二點 → 確認結果。全程不移動站位或改變鏡頭高度。

南北向同理。請同伴協助指出另一端投影點。畫面方向為輔助參考，羅盤受干擾時請用校園地圖或可靠羅盤確認；樹影不等於垂直投影。

04

什麼時候不能用？

斜坡、階梯、兩端地面不等高、看不清地面或樹頂、傾斜樹，以及角度不穩定時，請改用捲尺、專用工具或記為待測。

GPS 僅記錄樹的位置，不用來量冠幅。樹基俯角太小時，微小角度誤差會放大成明顯距離誤差。

Excel 與資料保存

匯出保留原課程的「填寫表、樹種對照表、參數設定、統計摘要、填寫說明」及計算公式，另加「量測原始紀錄」。手機估測一律填為「估計」。照片不足四張仍可保存原型紀錄，但課程檢核會顯示待補。

紀錄保存在目前瀏覽器；清除網站資料、使用無痕模式或更換手機可能失去紀錄。請定期匯出 Excel 與 JSON 備份。此版本尚未建立全班共用資料庫。

估算不包含土壤碳、枯枝落葉、草本及灌木，也未扣除維護碳足跡。模型來自森林林分，套用校園孤立木有不確定性；棕櫚及竹類不計碳。
